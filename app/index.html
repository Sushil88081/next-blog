Code Examples

Basic Promise

const promise = new Promise((resolve, reject) => {
    const success = true;
    
    if (success) {
        resolve("Operation successful! ✅");
    } else {
        reject("Operation failed! ❌");
    }
});

promise
    .then(result => console.log(result))
    .catch(error => console.log(error));

Promise Methods

.then()

Handles fulfilled promises. Returns a new promise for chaining.

promise.then(value => console.log(value))

.catch()

Handles rejected promises. Catches errors in the chain.

promise.catch(error => console.error(error))

.finally()

Executes regardless of promise outcome. Used for cleanup.

promise.finally(() => console.log("Done"))

Promise.all()

Waits for all promises to resolve. Fails if any promise rejects.

Promise.all([p1, p2, p3])

💡 Tip: Promises help you write cleaner async code compared to callbacks!
